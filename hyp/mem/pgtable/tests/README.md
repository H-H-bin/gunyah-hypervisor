# PGTable Module Test case

Two testcases are developed to test the pgtable module:
* testcase.c: contains batch test for basic testing. It is used to add specific
  testing with specific checking. Usually it's used to make sure the basic
  functionality is good.

* random_test: it reads operations from input file, and executes
  map/unmap/prealloc/checking functions. The input file can be automatically
  generated by the script **tools/pgtable_hyp_testcase.py**. This script will
  generate random memory mapping/unmapping/prealloc operations, can be useful
  for a stress test and code coverage test.

# Run Testcase
Before run testcase, we need to compile it to binary. The code could be compiled
on x86 development PC. (also could be running on arm, but need to adjust
Makefile).

To compile it for x86:
* Need to compile gunyah to generate necessary header file.
* Create a Makefile with the follow contents, and move it to
```<path-to-gunyah>/hyp/core/pgtable/```
* ```# make ``` for testcase
* ```# make rt``` for random_test

```
CC=clang-7
CXX=clang++-7
GENERAL_INCLUDES=-I../../interfaces/pgtable/include
GENERAL_INCLUDES+=-I../../../build/qemu/gunyah-baseline/debug/include
GENERAL_INCLUDES+=-I../../../build/qemu/gunyah-baseline/debug/events/include
GENERAL_INCLUDES+=-I../../../build/qemu/gunyah-baseline/debug/events/pgtable/include
GENERAL_INCLUDES+=-I../../interfaces/base/include
GENERAL_INCLUDES+=-I../../interfaces/hyp_aspace/include
GENERAL_INCLUDES+=-I../../interfaces/partition/include
GENERAL_INCLUDES+=-I../../interfaces/spinlock/include
GENERAL_INCLUDES+=-I../../misc/log_standard/include/
GENERAL_INCLUDES+=-I../../interfaces/util/include
GENERAL_INCLUDES+=-I../../interfaces/platform/include
GENERAL_INCLUDES+=-I./tests/
GENERAL_INCLUDES+=-imacros ../../interfaces/util/include/attributes.h
GENERAL_INCLUDES+=-imacros ../../core/spinlock_ticket/include/spinlock_attrs.h
GENERAL_INCLUDES+=-imacros ../../core/preempt/include/preempt_attrs.h
GENERAL_DEFS+=-DHOST_TEST
GENERAL_DEFS+=-DHYP_STANDALONE_TEST
GENERAL_DEFS+=-DPLATFORM_VM_ADDRESS_SPACE_BITS=48
GENERAL_DEFS+=-DPLATFORM_PGTABLE_4K_GRANULE
GENERAL_DEFS+=-DARCH_ARM_FEAT_XNX=1
GENERAL_DEFS+=-DARCH_ARM_FEAT_VHE=1
GENERAL_DEFS+=-DARCH_IS_64BIT
GENERAL_DEFS+=-DCPU_PGTABLE_BBM_LEVEL=2

CFLAGS+=-m64
CFLAGS+=-Wall -g -O3 -flto
CFLAGS+=$(GENERAL_INCLUDES)
CFLAGS+=$(GENERAL_DEFS)

LDFLAGS=-lstdc++

BIN=testcase
SUBDIR=$(shell ls -d */)
ROOTSRC=./armv8/src/pgtable.c ./tests/stub.c \
	../../misc/log_standard/src/string_util.c ./tests/mem_manager.cpp \
	../../../build/qemu/gunyah-baseline/debug/hyp/core/base/accessors.c
SUBSRC=./tests/testcase.c
SUBOBJ=$(SUBSRC:%.c=%.o)
ROOTOBJ=$(patsubst %.c,%.o,$(patsubst %.cpp,%.o,$(ROOTSRC)))

RANDOM_TEST=rt
RAN_SUBDIR=tests
RAN_SUBSRC=./tests/random_test.c
RAN_SUBOBJ=$(RAN_SUBSRC:%.c=%.o)

$(BIN):$(ROOTOBJ) $(SUBOBJ)
	$(CC) $(CFLAGS) ${LDFLAGS} $(ROOTOBJ) $(SUBOBJ) -o $(BIN)

$(RANDOM_TEST):$(ROOTOBJ) $(RAN_SUBOBJ)
	$(CC) $(CFLAGS) ${LDFLAGS} $(ROOTOBJ) $(RAN_SUBOBJ) -o $(RANDOM_TEST)

.c.o:
	$(CC) -std=c11 $(CFLAGS) -c $< -o $@

.cpp.o:
	$(CXX) -std=c++11 $(CFLAGS) -c $< -o $@

clean:
	rm -f *.o $(BIN) $(ROOTOBJ) $(SUBOBJ) ${RANDOM_TEST}
```

## Run Batch Test
After compilation, we can have ```testcase``` binary under
```<path-to-gunyah>/hyp/core/pgtable/```, just directly run ```# ./testcase```
should got the result.

## Run Random Test
To run random test, we need to use
```<path-to-gunyah>/hyp/core/pgtable/tools/pgtable_hyp_testcase.py``` to generate
random input file, steps:
* Use pip to install required module:
```
sortedcontainers==2.1.0
transitions==0.7.1
```
* make sure the ```rt``` is generated with ```make rt```
* enter ```<path-to-gunyah>/hyp/core/pgtable/tools/```, and run command like:
```# i=0; while [ 1 ]; do python3 pgtable_hyp_testcase.py > ../u.data && ../rt -f ../u.data; if [ $? -ne 0 ] ; then break; fi; echo "count  ${i}"; ((++i)); done ```
